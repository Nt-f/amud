## Fixes
- "Yihyu leratzon" on a line of its own, before or after Elohai Netzor, was set in large bold type as if a prayer began there. It is now plain and centered, in all five siddurim.
- Modim DeRabbanan and other long paragraphs the congregation says were set to one side like a short "Amen", and Modim DeRabbanan was faded with the chazzan's repetition. They are now set like the prayers around them.
- On Rosh Chodesh and other days with an addition, a short label before it, like "לר"ח:", left a gap in the highlighted line. It is now highlighted with the words.
